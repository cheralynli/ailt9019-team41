# Visual assets

- `board-background.png`: original photograph supplied by the user for this local design. It depicts Risk as decoration; Risk is not a supported ruleset. Confirm reuse rights before public distribution.
- `Federo-Regular.ttf`: Federo from the official google/fonts repository, under the accompanying SIL Open Font License.
- `DancingScript.ttf`: Dancing Script from the official google/fonts repository, under the accompanying SIL Open Font License.

Fonts are served locally, so viewing the interface makes no Google Fonts request. The lettering is inspired by the supplied reference, not an exact identification of its typefaces.
